# Career Pathfinder (for AI coding tools that read AGENTS.md)

All instructions for this workflow are in **`CLAUDE.md`** in this folder. Read it first and follow it exactly; its boundaries always apply.

- Detailed rules for each stage are skills in `.claude/skills/<name>/SKILL.md`. If your tool does not load skills automatically, open the skill named for each stage in the table at the end of `CLAUDE.md` before starting that stage.
- Worker roles are described in `.claude/agents/`. If your tool has no subagents, do those stages yourself, one at a time, following the same skills.
- Scripts are in `scripts/` and run from this folder; on Windows use `python` instead of `python3`.
- Everything the workflow saves goes in `workspace/`. Never open `workspace/personal.tex` after it is created.
